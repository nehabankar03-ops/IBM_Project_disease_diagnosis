# IBM_Project_disease_diagnosis
# 🩺 Diagnosis Prediction Using Machine Learning

A machine learning project developed to **predict diagnosis based on patient-related clinical features**. The project uses Python and Scikit-learn to preprocess the data, train a Random Forest classification model, and evaluate its performance using accuracy, classification report, and confusion matrix.

### 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest
* Jupyter Notebook

### 📌 Key Features

* Data preprocessing
* Handling missing values
* Numerical feature scaling
* Categorical feature encoding
* Machine learning model training
* Model evaluation
* Diagnosis prediction

This project was developed as an **academic machine learning project** to understand the complete workflow of a classification problem.
